# 一句话启动与可选补充

日常只需：

> 使用 $campus-world-build，复刻【学校】【校区】。

你以 Agent 为唯一创作工作台：说学校和想法、看结果、提修改即可。读取操作指南、检查连接、找地图照片、制作与验收都由 Agent 执行；真正需要本人登录或申请创作权限时，它会集中提醒。无需自己学习导入、摆楼或参数设置。

下面是想明确例外、预算或既有工程时的可选补充，不要求用户把默认流程重新说一遍。

使用 $campus-world-build 复刻【学校名称】【校区名称】。

目标：按学校官方地图还原整个校园的建筑、校门、道路、宿舍、食堂、体育场地等室外基础设施。由你自行找到官方地图，并逐栋真实检索、核实参考照片，再使用造世界编辑器的可用生成与编辑能力制作、落位、接地和验收。先把基础复刻完整，再考虑主题美化和玩法。

我可选提供的资料：【已有地图链接/照片/工程；没有可留空，由你先查】。
需要保留或排除的区域：【按当前已知约定；没有额外限制可留空】。
本轮资源边界：【可修改工程、已授权工具、成本/时间上限，沿用会话已确认内容】。

先从已有记录确认工程与当前状态，自行读相关操作指南、查可用工具。开工前建立全图要素清单、逐栋照片证据、统一布局与文字规格，并把地图全集和场景实际逐项对照。没有照片的地方先搜；身份不确定标缺口，不编造真实外观。

整个创作过程由你使用当前获权工具或界面自动化执行，不将编辑器操作教程变成我需要亲自完成的制作步骤。缺执行能力时告诉我实际缺什么，并先推进独立资料工作，不把资料整理当场景已建成。根据本轮首批实测给出时间预期，分清我需要参与多久、你的制作时间和平台等待；没有证据就不要承诺整校工期。

小样用于验证生成、比例、导入、保存，不代表只交付一栋楼一条路。方法通过后，自动循环：查资料→参考图组→生成/搭建→比照片→调整位置尺寸→接地检查→保存→更新清单→下一栋。普通可逆步骤直接做，每批完成后继续下一批，不需要等我说“继续”。

保持全校缺项优先：先补未建建筑和场地、缺完整楼体与悬空，再精修；不要反复测试同一局部路线。用“已达标/待修正/未做”报告全图变化，把文件生成、入库、入场、保存、看图和运行分开。

只有校园/建筑身份冲突、无法访问的必需资料、预算权限或重要审美取舍必须由我决定时，带已查证据和建议集中问一次。中断先读回再续接，避免重复生成和导入；不自动创建定时任务、购买、消耗重置卡或发布世界。

为长程执行建立持久检查点。外部写入前记录意图，回包后保存真实任务句柄和输入快照；未知结果先查原任务、资产与场景。每栋结束更新全图状态和短恢复卡，分项读取资料，失败次数、预算与缺口不能因上下文压缩丢失。不要把全部聊天重灌上下文，不把会话结束或队列空当全校园完成。宿主不可避免停止时保留恢复入口；我下次说“继续”就从实际状态接着做，不重新造一份。

---

如果 Agent 没识别 Skill，请让它读取你本机的 `campus-world-build/SKILL.md`。这份任务用于减少重复补充和催促，实际效果仍取决于照片证据、编辑器能力、预算与验收。

想保留自己的用法时，直接说：“基于这套 Skill，在这个项目里为我的校园建立专属版本，把已确认的风格和实测有效的做法留下来。”Agent 会保留通用流程，在项目内保存差异；不需要你手写代码，也不会默认覆盖全局版本或公开上传。
