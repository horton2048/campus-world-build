# 可直接复制的启动任务

使用 $campus-world-build 帮我在造世界编辑器中构建校园。

我的校园/校区：填写名称。
参考资料：给出地图、建筑照片或现有项目文件夹。
编辑器资料：给出操作指南、相关教程或已保存的阅读笔记。
工具连接：优先使用我已经安装并授权的造世界 MCP；当前是否连接可由你核验。
体验构想：希望同学进来以后先看到什么、做什么、带走什么。
这轮范围：要做的区域，以及要保留不动的区域。
完成标准：例如建筑位置准确、入口能走通、主题装饰可辨认、一个交互能够重复运行。

先读取已有对话、项目状态与本轮相关的官方教程，写明关键规则及其适用前提。再发现当前实际可用的工具，区分原生 AI 生成、MCP 编辑与需要界面操作的部分。已有连接直接核验；新增安装或权限调整按本会话授权处理，不从示例继承。

已知的信息直接采用；缺失的信息先查材料，再只问真正影响制作的问题。先做一个最小样板验证比例、朝向、碰撞、保存及读回，再分区扩建。每轮留下截图、资产/实例映射、已通过/待验项和下一步，方便断线后接着做。遇到功能无效时先核文档前提和对象类型，不无依据重复调参数。

我负责提供参考、选主题和判断效果；你在本轮授权范围内完成任务拆解、生成/复用、坐标、脚本、导入、落位、保存与核验。费用、容量和发布范围按我们本次约定执行。不要自动发布世界。
