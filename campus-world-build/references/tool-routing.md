# 当前工具路由与前置条件

先读 [当前 MCP 开工](guide-and-mcp.md)；需要操作时查 [原生执行](native-execution.md) 和当前底座 `tool-guide`。以下是定位入口的提示，不是完整 CLI 手册。工具是否注册、参数形状、目标工程准入及当前版本的实际结果优先于历史名称。

| 要做什么 | 当前入口 | 关键核对 |
|---|---|---|
| 确认编辑器与工程 | `awc_editor_status`、`awc_project_list/get`、`awc_cli_help` | 在线、已登录、精确项目身份与可操作范围分别确认 |
| 阅读执行方法 | `awc_skill_read` 读取当前可用的 `world-production`、`tool-guide`、`campus-world-build` | 用实际 schema；单独安装 Skill 不会附送编辑器或连接 |
| 组织制作与续做 | 经 MCP→CLI 使用 `world create/next/dispatch/settle/control` | 主 Agent 派发真实会话；CLI 不启动 Agent，工作单不等于执行证据 |
| 资产、摆放、地形、脚本与保存 | `awc_cli_run` 调用帮助中存在的对应原子能力 | 先读本轮输入合约；以原生尺寸、句柄、保存回读验真，不猜不存在的接口 |
| 查询与检查 | `awc_cli_read` 或当前专用只读工具 | 仅其允许的命令；大场景区分完整计数与截断节点清单 |
| 官方生成 | `awc_generation_capabilities/preflight`，再经 MCP→CLI 调用当前 `generate` 命令 | 沿用本轮费用授权；保存真实任务 ID，等待全部终态，不把粗模当最终资产 |
| 正常试玩与画面 | 经 MCP→CLI 使用支持的 `runtime` 与截图命令 | 正常输入后独立读回游戏结果；静态截图不代表走路、碰撞或动态画面通过 |
| 已保存正式工程审计 | 当前版本支持时，使用精确名称/路径/源 SHA 的审计选项 | 只读与正常试玩，不支持施工、保存或媒体控制；不能借此扩大写权限 |

CLI 1.0 底座已移除旧整世界制作、pipeline 与旧质量命令；以当前帮助为准，不照搬旧桥工具或旧 `awc_world_make`。版本不兼容时记录具体缺口，不能用同名旧接口的历史成功补当前证据。

对已有校园，先核所有必要动作是否支持其正式工程身份。用户拒绝复制或备份时保持该约定；当前只支持 TEST 施工、或保存强制生成备份时，暂停相应写入并说明能力缺口，不改名绕过。用户禁止电脑操作时，不回退到界面或旧桥。

发布、购买、充值等依据当前用户授权，不从制作任务或历史案例自动推导。普通已授权制作由 Agent 执行并验收，不把导入、摆楼、调参或保存转交新手手工代做。
