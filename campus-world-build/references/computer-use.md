# 电脑操作：无 MCP / CLI 时的编辑器路径

在用户允许电脑操作且当前 Agent 实际具备操作与查看屏幕的工具时使用；用户明确禁止则不得使用。先核工具使用说明、编辑器版本和登录状态。无法控制编辑器或无法辨认界面时报告缺口，继续资料工作，不假装已经施工。

先确认目标工程及未保存状态。对已有正式工程，先用界面支持的完整复制功能建独立测试副本，核对源与副本身份；不确定复制完整、无法确认项目或无法安全备份时停止写入。不要用手改项目文件代替复制。

每轮先观察真实界面，确定当前对象、工具、场景和状态，再小步执行；选中对象后核名称，读取可见的坐标、旋转、缩放与属性，按实际控件输入并重新观察。画面变化后重新观察，不能盲点或假设固定按钮位置。无法可靠读取尺寸或坐标时标记精度受限，先小样，不能宣称精确复刻。

生成、导入、删除、保存等先记录意图及可见名称/时间/状态；等待明确完成。超时或中断时先检查任务列表、资产库和场景，不重复提交可能收费或重复创建的操作；无法辨明则暂停并报告。保存后确认界面反馈，按可用能力正常退出重开，复查对象、属性、外观与玩法；保存回执、资产ID、实例ID、revision等仅在界面确实可见时记录，缺失就标未验证，不得编造。

Agent查看截图并对照参考图，实际试玩可达路径和交互；截图存在不等于通过。UI 能力、画面精度和会话限制可能影响速度、精确性及续做；不能声称和原生接口等效。每轮留实际截图、对象标识、未完成项和下一步，恢复时先核现场。切换操作入口前先确认一致状态，同一工程避免并行写入。
