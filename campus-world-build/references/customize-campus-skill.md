# 从通用 Skill 迭代校园专属 Skill

当用户说“把这些偏好留下来，以后都这样做”“为我的学校定制 Skill”或明确批准保存可复用做法时使用。普通的“这栋颜色淡一点”先作为当前作品修改，不擅自升级为所有未来建筑的规则。Agent 负责文件与验证，用户用自然语言表达和确认即可。

## 先区分三种信息

| 信息 | 保存位置 | 例子 |
|---|---|---|
| 校园稳定事实与用户确认偏好 | 专属 Skill 的校园设定引用 | 校区身份；只保留夜景主题；用户确认的校园导览主线 |
| 经当前版本实测有效、可复用的做法 | 专属 Skill 的经验引用 | 同一来源的导入校准及适用条件、某类建筑处理方法 |
| 本轮状态与未经验证的尝试 | 现有任务约定、检查点或试验记录 | 正在生成哪栋、任务句柄、余额、当前坐标、待验证的新交互 |

“它会更好看”是创意候选，不是验证结论；历史某座校园的数值也不能成为所有学校的固定参数。用户喜欢的变化不自动证明技术实现已通过。

## 首次派生

1. **确认保存范围。**从用户已经明确的请求和反馈提取校园身份、目标阶段、风格偏好、保留区及欲复用经验。只有范围有歧义才集中确认；已有明确的定制授权不重复索批。
2. **在任务项目内完整复制。**将当前通用 `campus-world-build` 文件夹复制到项目中的 `skills/<campus-slug>-world-build/`，保留 `references/`、`assets/`、`scripts/` 等依赖。命名用小写字母、数字和连字符，不超过 64 字符；不要覆盖已安装的全局 Skill 或通用仓库。
3. **让副本可独立定位。**更新副本 `SKILL.md` 的 `name`、描述，及包内正文、启动模板和 UI 元数据中用于调用本 Skill 的名称与提示；保留标准文件名和其他政策字段，不把上游来源名替换掉。记录基线版本/来源（无可用提交号则标日期与本地快照）。在项目 `CAMPUS_TASK.md` 中登记专属 Skill 路径和启动方式；不改正在使用的检查点和真实任务 ID。
4. **只追加明确的校园差异。**在副本中新增 `references/campus-profile.md`，由 `SKILL.md` 明确指向。记录校园事实来源、用户确认偏好、适用范围、实测方法和仍待验证点；不要把整段聊天或大图片嵌入指令。用户自己的参考素材留项目素材目录，用相对路径索引。
5. **保留通用可靠性约束。**地图全量盘点、逐楼照片依据、完整楼体与接地、未知作业查重、原生保存回读、持续循环和中断续做继续生效。风格变化不允许消除未完成项；完整范围只有用户明确变更才调整。
6. **验证并交付入口。**核对内部引用都能在副本或明确的项目资料中定位，启动名称一致。项目内的 `skills/` 目录不保证被宿主自动发现：实际核验当前宿主能否加载；未发现时用“读取并使用【该副本的实际绝对路径】下的 SKILL.md”作为明确入口，不声称名称调用已可用，也不为此擅自安装全局。用一项已知校园需求做无外部写入的规则演练，确认会采用专属偏好且保留完整校园目标。实际生成/编辑效果须另按当前授权试跑；文件检查不算实机场景通过。给用户一句已核对的调用方式与本次保存了什么。

派生只发生在项目内，不默认安装到其他工具、覆盖全局、上传素材、创建公开仓库或发布世界。用户明确要求开源/安装时再按该范围执行。通用 Skill 的 MIT 许可不自动覆盖第三方照片、官方资源、私有指南内容或账号数据。

## 后续每轮怎样迭代

接收用户反馈 → 实际修改作品并验结果 → 将已确认的通用偏好/有效方法提炼为短规则 → 更新专属引用与变更记录 → 针对受影响部分检查 → 继续校园队列。用户直接要求先写一个待试用方法时可以保存，但明确标为试验，不冒称已验证。

每条规则保留“适用范围、来源/用户决定、动作、通过条件、版本限制”。更改前保留可恢复版本；用户的新意见覆盖旧偏好时，标明替代关系，不保留相互矛盾的强制规则。优先更新现有条目，不每次反馈新堆一份文件。创意方案只记必要选择，状态继续留在检查点。

通用版本以后升级时，先比较基线与新版本，应用与本项目相关的修复，再复核专属差异；不能用整包覆盖抹掉用户偏好，也不能把旧校园的临时限制强行带入新环境。

## 用户可以直接这样说

> 基于这套 Skill，为我的校园建立一个专属版本。保留已经确认的校园范围与制作流程，把我选定的风格和这次实测有用的做法保存下来；我以后只需要描述想改哪里，你来更新作品和相关规则。

> 以后我的校园都用这个配色和夜景氛围。请保存成这个校园的默认偏好，不影响其他校园；没有验证过的实现先标待试。

用户无需知道文件结构或写代码。Agent 的交付应说清“下次用什么名称启动、哪些偏好已记住、哪些效果仍待试”，并继续使用原工程与恢复记录。
