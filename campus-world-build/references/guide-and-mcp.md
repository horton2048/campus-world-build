# 操作指南、MCP 和 Skill 分别解决什么

本页依据 2026-10-10 至 10-26 的校园制作记录，于 2026-10-29 复盘。链接提供来源，不保证当前版本菜单、权限与限制保持不变。

## 每次接手的顺序

1. **读懂本轮规则。**主动定位当前官方指南，并优先利用用户已提供的资料及与任务有关的案例，提取“动作、前提、输入输出、限制、验收办法”，保留链接、日期和适用版本。复用已有阅读笔记，新增功能或版本变化时才补读；不要求每次把所有教程重读一遍。
2. **核对实际能力。**发现当前编辑器/MCP 工具，读取 schema，建立简短的动作映射。教程中的 UI、示例代码和旧工具名不能直接变成当前可调用接口。
3. **技术校准后持续执行全图。**已验证环境沿用现有证据；新环境或新导入路径先用最小对象验证读场景、导入/落位、变换读回、保存/重开和画面。先证明方法可用，再按全图缺项复制到后续资产；小样不缩小总范围，也不把下一批变成新的确认请求。
4. **固化为 Skill。**保存已验证流程、前提、失败处理与检查点。保留“文档描述”“实际调用成功”“画面/运行通过”三种证据层次，不相互替代。

## 这次官方指南实际起了什么作用

10 月 10 日已读取官方指南链接的 **19 篇教程、FAQ 与社区案例**，形成逐篇文本和制作流程笔记。它帮助选择静态模型、原生 Agent、模块组装或 MIX；区分入库与落场、碰撞与重力；建立本地运行、手机预览、多人及发布的不同验收阶段。阅读记录不证明所有内嵌视频已观看，更不证明所有功能都做过实测。

一个真实例子是刷草。教程要求在“地形表面”操作；当时的校园底板是导入的 GLB，尝试后 UI 提示“当前场景暂无地形”，草数量没有增加。于是改用真实绿地与道路边界约束的批量草层生成，三片区域完成原生归档、落位、保存和局部穿行。它证明换路径有效，不能说笔刷已经成功，也不能说全校草地或手机性能已验。

## 社区 MCP 实际起了什么作用

来源：[WilderNoTrack/world-creator-mcp](https://github.com/WilderNoTrack/world-creator-mcp)。它是社区适配器，不是官方指南，也不是本 Skill 自带安装包。

10 月 15 日在用户明确授权下做 Mac 适配：调整启动方式及路径/子进程环境传递，限制写入范围，在独立测试工程验证。记录为 **53 项隔离测试通过、33 步核心实机调用通过**，包括导入与落场、位置/旋转/缩放读回、组件 schema、Lua、原生保存及重开。测试使用的是当时经过本地改造的适配器版本，不代表社区上游在其他 Mac 上开箱即用。当天发现 56 个工具，不等于 56 个功能全部完成 Mac 验收；PCG 云生成、发布、所有对象类型等仍未全测。

10 月 16 日按后续授权把校园加入可写范围并重连，随后实际使用 MCP 读场景、导入资产、创建实例、落位、修改受支持组件和保存。10 月 15 日的“仅测试项目”是当时边界，不能当作后续校园未使用 MCP 的证据；反过来，历史校园授权也不能带到另一位用户或新项目。

复用已有安装与授权。新接入时读来源与实现边界；若需要新的安装、内部编辑连接或权限变更，先核对当前任务授权。不要自动安装陌生服务，不绕过适配器写场景缓存，不照抄历史本地地址、项目 ID 或白名单。

## 四层分工

| 层 | 在这次流程中的作用 | 不能据此承诺 |
|---|---|---|
| 官方指南与示例 | 告诉 AI 怎么选入口、哪些前提成立、怎样保存和验收 | 看过文档就已实测；旧参数永远适用 |
| 原生 AI / 编辑器 | 生成选定的模型或交互模块，运行实际世界 | 每种模块都由 MCP 一次调用生成 |
| MCP 与真实 UI | MCP 做结构化读写与回读；相机、未覆盖入口和实际操作由 UI 补充 | 所有操作都被接口覆盖；连接成功即能修改任意项目 |
| Agent + Skill | 将目标、知识、工具与证据组织成可续接的流程 | Skill 自己提供账号权限或替代玩家体验判断 |

## 证据范围

这些案例基于教程阅读笔记、独立工程测试、校园部署与验收记录整理。原始会话、场景文件、照片与日志未随本仓库公开；上面的公开来源链接仅用于了解背景，部分官方链接可能需要权限。Skill 是事后对经验的整理，不能据此称当时的每一步都已经由本 Skill 执行或通过审计。将方法用于自己的项目时，请保留自己的规则、动作与验收证据。
