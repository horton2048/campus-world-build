# 自主施工、验收与修正

## 建立可执行约定

记录需求来源和已对齐目标、现有工程、参考图/地图版本、本轮范围与保留项。Agent将它转成可检查的标准和方法；纯观赏、竞速、社团等各自验，不套一个固定玩法。能力检查分已验证/需小样/当前缺口；有疑问先小样，不先承诺任意需求全自动。

已有校园：先只读核对工程身份和现场，确认未保存状态，创建并核验完整独立测试副本后才修改。MCP 路径按实际CLI合约检查场景与容量、使用完整副本并核对独立worldId和源不变；电脑操作路径按 [电脑操作](computer-use.md) 核对界面可见证据。无法可靠复制或验证时暂停修改正式工程。不从限制性terrain checkpoint fork复制正式校园。

## 每轮

1. 恢复原任务/回执/现场。选有明确交付体验且可独立验收的一轮（建筑+入口路段、比赛一段+检查点、一个社团摊位+反馈，或一批旧资产清理）。
2. 写本轮目标、完成标准、保护项、验证方法与可获得的前态证据。记录意图，再按已选入口执行；同一场景只有一个写入负责人。
3. 经当前入口核对真实任务、资产、实例与位置及生成终态；不可见的句柄或revision标记未验证。超时或unknown先查询原任务/现场，不自动重复收费生成、导入、落场或删除。
4. 自主验三层：操作/持久化；地图照片/体量朝向风格；正常走路/交互反馈/完整局部循环。看实际PNG，不以文件存在当视觉通过。
5. 失败定位到资料、模型、变换、碰撞、脚本或能力，做最小必要修正再验受影响项。连续无改善换诊断/方法，重大取舍才问用户；原要求保留，不能降标准求通过。
6. 通过后保存、更新检查点与剩余队列。所有局部通过后整体串联试玩、容量检查、正常保存完全退出冷开，重新核同一版本，再交付。未测平台、任务和视觉区域明确分开。

## 已有建筑美化的保护约定

本节具体 schema 和命令属于 MCP 路径；电脑操作时以实际可见的对象属性、截图和可验证的界面能力执行同等保护，不假装能读取隐藏字段。

先清点全部建筑（根/子模块分开），冻结原名、层级、真实世界位置/朝向、尺寸、占地、入口、碰撞、脚本与外部ID引用；非建筑的路、地面、植被和活动不自动纳入。

先分清用户要统一材质，还是重做模型造型。编辑器外观面板的原生“卡通”是 `Appearance.PresetName=NPR`；生成器的卡通是 `cartoon=1`（`minimal=2`另有用途）。两者独立：统一现有校园外观时优先小样验证NPR，保留原几何、ID、位置、碰撞和脚本；需要改变轮廓/细节时再走生成。不能把材质切换写成“重新生成全部建筑”，也不能把改资产style标签或仅调色写成已用官方卡通生成。

材质施工从建筑根追到实际含Appearance的子节点，核对原生schema，再用 `scene edit-inspect` 的 `appearanceInstanceIds` 与 `scene edit-apply` 的 `preset-material` 动作。预设切换可能通过官方side effects重置原Color，使窗户和墙体变成同色；先冻结原生Color，切换时保留，必要时以原HEX显式修复并重新看图。组件全部显示NPR不代表美化通过。冻结全部非外观数据，分批记录/回读/保存；组合楼群不必拆开或移动，保留模型生成路线作为可选的独立候选。

优先保留现有几何/ID/脚本的可行美化方法。必须重生成/换模型时先小样，使用原建筑参考，检查辨识特征和完整楼体；记录旧→新ID映射。替换可能清子树与脚本，不能盲替有玩法建筑；先解决引用、碰撞与入口保护。新模型枢轴不同，照抄transform并不能证明世界位置不变；保持原约定的世界位置、朝向与建筑锚点，实测占地和门口，不能移动整栋来掩盖模型错误。没有可靠保护链时保留候选，明确阻塞，不在原校园批量试错。

验收逐栋记录：同名、位置朝向不变、风格统一且仍可辨认、入口通路/碰撞/玩法保持、容量、保存冷开。只完成一栋不能标整校完成；所有建筑要有稳定清单及未做/待修正/达标状态。

## 大场景

以下具体命令属于 MCP 路径；电脑操作时以可见信息检查，无法核实的容量、位置或持久化证据标记缺口。

原生容量按真实节点分项统计，确认audit无截断且总账一致；隐藏/压缩素材库不等于减少世界容量。`scene edit-* --summary` 保留完整revision和磁盘回执，避免MCP输出超限。项目超过默认512MiB源校验预算时可显式 `runtime observe --manifest-max-bytes`，保持流式完整源哈希与前后核验；这不改变引擎容量上限。

普通移动相对当前镜头，不能将W固定当作世界某一轴；用实际SDK朝向和位置反馈逐段行走，卡住先看现场/重选通路，禁止反复顶墙或用调试传送冒充步行通过。可通过作品原有的快行/传送菜单验玩法，但明确记录该段为正常玩法传送，另验落点与局部步行。UI路径和规则以当前已注册脚本及实际现场为准，历史生成工作区不能代替现行版本。冷开按当前帮助通过 MCP 调用 `editor close`，确认整个编辑器正常退出后再用 `editor start/open`；从回执和真实场景核对，不重复未知打开。当前底座没有旧的 `editor launch` 命令。
